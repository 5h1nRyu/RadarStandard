# 可下载的示例作品

下载 [RadarStandard-test-work.zip](RadarStandard-test-work.zip?raw=true)，解压后在网页点击「导入作品文件夹」，选择直接包含 `work.json` 的 `radar-test-work` 文件夹。

包内包含：

- 4 位虚构选手，完整轮播 24 秒。
- 数据 JSON、全部静态 SVG 图片及完整布局。
- 17 个组件，覆盖全部 10 类组件与三种绑定来源。
- `layout-empty.json`，可导入以测试从空白布局添加组件。
- 中文使用说明。

本示例仅提供测试数据和素材，不包含主题代码。使用项目内置 `classic` 主题。
